# Contributing to VectraBank

Thank you for contributing to VectraBank!

## Contribution Workflow
1. Fork the repository.
2. Create a feature branch: `git checkout -b feature/my-feature`.
3. Ensure all tests pass: `pytest tests/`.
4. Commit using conventional commit format: `feat:`, `fix:`, `docs:`, `test:`.
5. Push to your branch and open a Pull Request.

## Coding Standards
- Python code formatted with `black` and type-annotated where applicable.
- React components structured cleanly with modular hooks.
- Never commit credentials or `.env` files.
